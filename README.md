🎵 Music Player Web App

A simple and interactive web-based music player that allows users to play, pause, skip, and loop their favorite songs directly in the browser.

Features

Play and pause songs

Skip to the next or previous track

Loop or shuffle tracks

Displays song title and duration

Responsive design for desktop and mobile
